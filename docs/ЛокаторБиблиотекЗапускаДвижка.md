# ЛокаторБиблиотекЗапускаДвижка

Публичный объект для разрешения библиотечных путей и статического поиска каталогов библиотек. Локатор
создаётся по конфигурации запуска и хранит неизменяемый снимок настроек `lib.system` и `lib.additional`.

## Создание

```bsl
Локатор = Новый ЛокаторБиблиотекЗапускаДвижка(Конфигурация);
```

| Имя | Тип | Описание |
| --- | --- | --- |
| Конфигурация | `КонфигурацияЗапускаДвижка` | Конфигурация, библиотечные пути которой нужно разрешить. |

Относительные пути разрешаются при создании локатора. Последующие изменения конфигурации на него не влияют.

**Исключения:**

- `argument.invalid_type` - `Конфигурация` имеет неверный тип.
- `engine_config.path_unresolved` - библиотечный путь не удалось разрешить.
- `engine_config.invalid_configuration` - разрешённый путь `lib.additional` содержит разделитель списка.

## Методы

### ПолучитьСистемныйКаталог

```bsl
Локатор.ПолучитьСистемныйКаталог()
```

**Возвращаемое значение:** `Строка, Неопределено` - абсолютный системный каталог либо `Неопределено`.

### ПолучитьДополнительныеКаталоги

```bsl
Локатор.ПолучитьДополнительныеКаталоги()
```

**Возвращаемое значение:** `Массив из Строка` - независимый массив абсолютных путей `lib.additional`.

### ПолучитьКаталогиПоиска

```bsl
Локатор.ПолучитьКаталогиПоиска()
```

**Возвращаемое значение:** `Массив из Строка` - независимый массив абсолютных путей: сначала дополнительные
каталоги в исходном порядке, затем системный каталог. Повторы исключаются с сохранением первого вхождения,
отсутствующие каталоги сохраняются.

### НайтиБиблиотеку

```bsl
Локатор.НайтиБиблиотеку(<Имя>)
```

Возвращает первый существующий каталог `<КаталогПоиска>/<Имя>`.

| Имя | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Непустое имя без крайних пробелов, `/`, `\`, `:`; не `.` и не `..`. |

**Возвращаемое значение:** `Строка, Неопределено` - абсолютный путь к первому каталогу либо `Неопределено`.

Метод не проверяет содержимое каталога и не запускает загрузчики пакетов.

**Исключения:**

- `argument.invalid_type` - `Имя` имеет неверный тип.
- `argument.required` - `Имя` пусто или состоит из пробелов.
- `argument.invalid_value` - `Имя` содержит путь, крайние пробелы или равно `.` либо `..`.
