# ФабрикаКонфигурацийЗапускаДвижка

Публичный модуль для создания готовых независимых конфигураций из типовых источников. Для произвольного
объединения источников используйте [ПостроительКонфигурацииЗапускаДвижка](ПостроительКонфигурацииЗапускаДвижка.md).

## Функции

### СоздатьДляТекущегоЗапуска

```bsl
ФабрикаКонфигурацийЗапускаДвижка.СоздатьДляТекущегоЗапуска()
```

Создает конфигурацию из трех стандартных источников в порядке приоритета:

1. `<КаталогДвижка>/bin/oscript.cfg`;
2. `oscript.cfg` рядом со стартовым сценарием;
3. текущее `OSCRIPT_CONFIG`.

Отсутствующие CFG пропускаются. Существующий поврежденный CFG или некорректное значение `OSCRIPT_CONFIG`
вызывает ошибку.

**Возвращаемое значение:**

`КонфигурацияЗапускаДвижка` - новая изменяемая конфигурация текущего запуска.

**Исключения:**

- `engine_config.calculate_failed` - не удалось прочитать, разобрать или объединить источники.

### СоздатьИзФайла

```bsl
ФабрикаКонфигурацийЗапускаДвижка.СоздатьИзФайла(<Путь>)
```

Создает конфигурацию из одного обязательного CFG-файла.

| Имя | Тип | Описание |
| --- | --- | --- |
| Путь | `Строка` | Непустой путь к CFG-файлу. |

Относительный путь разрешается от текущего каталога. Отсутствующий, поврежденный или недоступный файл является
ошибкой.

**Возвращаемое значение:**

`КонфигурацияЗапускаДвижка` - новая изменяемая конфигурация из файла.

**Исключения:**

- `argument.invalid_type` - `Путь` имеет неверный тип.
- `argument.required` - `Путь` пуст или состоит из пробелов.
- `engine_config.calculate_failed` - не удалось прочитать или разобрать файл.

### СоздатьИзТекущегоОкружения

```bsl
ФабрикаКонфигурацийЗапускаДвижка.СоздатьИзТекущегоОкружения(<РабочийКаталог> = Неопределено)
```

Создает конфигурацию из текущего значения `OSCRIPT_CONFIG`.

| Имя | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| РабочийКаталог | `Строка, Неопределено` | `Неопределено` | Существующий каталог - база относительных библиотечных путей. |

Если каталог не передан, относительные библиотечные пути разрешаются от текущего каталога. Отсутствующее или
пустое значение `OSCRIPT_CONFIG` создает пустую конфигурацию.

**Возвращаемое значение:**

`КонфигурацияЗапускаДвижка` - новая изменяемая конфигурация из текущего окружения.

**Исключения:**

- `argument.invalid_type` - `РабочийКаталог` имеет неверный тип.
- `argument.required` - `РабочийКаталог` пуст или состоит из пробелов.
- `argument.invalid_value` - `РабочийКаталог` не существует или не является каталогом.
- `engine_config.calculate_failed` - не удалось разобрать настройки окружения.

### СоздатьИзНастроекОкружения

```bsl
ФабрикаКонфигурацийЗапускаДвижка.СоздатьИзНастроекОкружения(
    <СтрокаНастроек>, <РабочийКаталог> = Неопределено
)
```

Создает конфигурацию из явно переданной строки в грамматике `OSCRIPT_CONFIG`.

| Имя | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| СтрокаНастроек | `Строка` | - | Настройки, включая допустимую пустую строку. |
| РабочийКаталог | `Строка, Неопределено` | `Неопределено` | Существующий каталог - база относительных библиотечных путей. |

Если каталог не передан, относительные библиотечные пути разрешаются от текущего каталога.

**Возвращаемое значение:**

`КонфигурацияЗапускаДвижка` - новая изменяемая конфигурация из переданных настроек.

**Исключения:**

- `argument.invalid_type` - `СтрокаНастроек` или `РабочийКаталог` имеет неверный тип.
- `argument.required` - `РабочийКаталог` пуст или состоит из пробелов.
- `argument.invalid_value` - `РабочийКаталог` не существует или не является каталогом.
- `engine_config.calculate_failed` - не удалось разобрать настройки окружения.
