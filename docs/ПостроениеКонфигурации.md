# Построение конфигурации

`ПостроительКонфигурацииЗапускаДвижка` объединяет только явно добавленные источники. Это делает порядок
приоритетов видимым в вызывающем коде и исключает неявное чтение состояния процесса.

## Пустая конфигурация

```bsl
#Использовать engine-config

Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка().Построить();
```

Пустой построитель не читает CFG и `OSCRIPT_CONFIG`. Результат не содержит настроек и каталогов поиска.

## Явные источники

```bsl
Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка()
    .ДобавитьФайлКонфигурации("config/base.cfg")
    .ДобавитьФайлКонфигурации("config/local.cfg")
    .ДобавитьНастройкиОкружения(
        "lib.additional=./lib;encoding.script=utf-8",
        "C:/Projects/example"
    )
    .Построить();
```

Источники применяются в порядке добавления: каждый следующий источник перекрывает предыдущий для одноименных
настроек без учета регистра. Каталог каждого CFG служит базой его относительных библиотечных путей. Для строки
окружения база передается отдельно.

Явно добавленный CFG обязателен по умолчанию. Вызов
`ДобавитьФайлКонфигурации("config/optional.cfg", Ложь)` пропускает файл, если он отсутствует. Путь фиксируется
при добавлении, но содержимое перечитывается при каждом построении.

## Текущее окружение

```bsl
Построитель = Новый ПостроительКонфигурацииЗапускаДвижка();
Построитель.ДобавитьТекущееОкружение();
```

`OSCRIPT_CONFIG` и текущий каталог перечитываются при каждом `Построить()`. Чтобы зафиксировать базу, можно
явно передать существующий рабочий каталог. Пустое или отсутствующее значение не добавляет настроек.

## Текущий запуск

```bsl
Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка()
    .ДобавитьИсточникиТекущегоЗапуска()
    .Построить();
```

Метод добавляет:

1. системный CFG текущего движка;
2. CFG рядом со стартовым сценарием;
3. текущее окружение.

То же самое с явной передачей источников:

```bsl
КаталогДвижка = Новый Файл(ОбъединитьПути(КаталогПрограммы(), "..")).ПолноеИмя;

Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка()
    .ДобавитьФайлКонфигурации(
        ОбъединитьПути(КаталогДвижка, "bin", "oscript.cfg"),
        Ложь
    )
    .ДобавитьФайлКонфигурации(
        ОбъединитьПути(СтартовыйСценарий().Каталог, "oscript.cfg"),
        Ложь
    )
    .ДобавитьТекущееОкружение()
    .Построить();
```

Автоматические CFG пропускаются только при отсутствии. Их пути фиксируются при добавлении, содержимое
перечитывается. `OSCRIPT_CONFIG` и текущий рабочий каталог читаются вместе при каждом построении.

Составной источник занимает позицию вызова:

```bsl
Построитель
    .ДобавитьФайлКонфигурации("config/before.cfg")
    .ДобавитьИсточникиТекущегоЗапуска()
    .ДобавитьФайлКонфигурации("config/after.cfg");
```

`config/after.cfg` добавлен последним и перекрывает одноименные настройки окружения текущего запуска.

## Побочные эффекты

Построение:

- не меняет текущий каталог процесса;
- не изменяет `OSCRIPT_CONFIG`;
- не записывает CFG;
- возвращает независимую изменяемую конфигурацию.

## Ошибки

Ошибки чтения, разбора и объединения оборачиваются кодом
`КодыОшибокEngineConfig.РасчетКонфигурацииНеВыполнен()`. Ошибка не удаляет зарегистрированные источники:
после исправления внешнего файла тот же построитель можно использовать повторно.
