# Поиск библиотек

`ЛокаторБиблиотекЗапускаДвижка` разрешает библиотечные пути одной или нескольких конфигураций и выполняет
простой статический поиск каталога библиотеки. При создании он сохраняет неизменяемый снимок настроек
`lib.system` и `lib.additional`.

```bsl
Локатор = Новый ЛокаторБиблиотекЗапускаДвижка(Конфигурация);
```

В конструктор также можно передать массив конфигураций. Последующие изменения конфигураций на уже созданный
локатор не влияют.

## Раздельные каталоги

```bsl
СистемныеКаталоги = Локатор.ПолучитьСистемныеКаталоги();
ДополнительныеКаталоги = Локатор.ПолучитьДополнительныеКаталоги();
```

Системные и дополнительные каталоги возвращаются независимыми массивами абсолютных путей в порядке
конфигураций.

## Порядок каталогов

```bsl
Каталоги = Локатор.ПолучитьКаталогиПоиска();
```

Для каждой конфигурации возвращаются абсолютные пути:

1. элементы `lib.additional` в исходном порядке;
2. `lib.system`;

Затем обрабатывается следующая конфигурация. Повторы исключаются с сохранением первого вхождения, отсутствующие
каталоги сохраняются.

## Поиск каталога библиотеки

```bsl
Каталог = Локатор.НайтиБиблиотеку("my-library");
```

Для каждого каталога поиска проверяется путь `<КаталогПоиска>/<Имя>`. Возвращается первый существующий каталог
либо `Неопределено`.

Имя должно быть непустой строкой:

- без крайних пробелов;
- без `/`, `\` и `:`;
- отличной от `.` и `..`.

## Ограничения

Поиск является статическим. Он:

- не проверяет наличие файлов `.os`;
- не запускает локальный или системный `package-loader.os`;
- не моделирует импорты относительных путей в кавычках;
- не гарантирует, что найденный каталог успешно загрузится движком.

Даже пустой каталог библиотеки считается совпадением и затеняет одноимённые каталоги с меньшим приоритетом.
