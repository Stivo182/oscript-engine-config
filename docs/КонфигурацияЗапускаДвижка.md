# КонфигурацияЗапускаДвижка

Публичный изменяемый объект конфигурации запуска. Хранит строковые настройки без учёта регистра ключей и базы
относительных библиотечных путей.

## Создание

```bsl
Новый КонфигурацияЗапускаДвижка()
```

Создаёт пустую конфигурацию без явно заданного базового каталога.

## УстановитьБазовыйКаталог

```bsl
Конфигурация.УстановитьБазовыйКаталог(<Каталог>)
```

Задаёт базовый каталог для последующих настроек. Уже добавленные настройки сохраняют свои базы.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Каталог | `Строка, Неопределено` | База последующих настроек без преобразования пути. `Неопределено` включает использование текущего каталога в момент установки настройки. |

Каталог может не существовать. Метод ничего не возвращает.

## ПолучитьБазовыйКаталог

```bsl
Конфигурация.ПолучитьБазовыйКаталог()
```

Возвращает базовый каталог в сохранённом виде, не преобразуя его в абсолютный путь.

**Возвращаемое значение:**

`Строка, Неопределено` - база последующих настроек либо `Неопределено`, если используется текущий каталог в момент
установки настройки.

## Содержит

```bsl
Конфигурация.Содержит(<Ключ>)
```

Проверяет наличие настройки без учёта регистра.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Ключ | `Строка` | Ключ настройки. |

**Возвращаемое значение:**

`Булево` - `Истина`, если ключ присутствует, в том числе с пустым значением.

## ПолучитьЗначение

```bsl
Конфигурация.ПолучитьЗначение(<Ключ>)
```

Возвращает значение настройки без учёта регистра.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Ключ | `Строка` | Ключ настройки. |

**Возвращаемое значение:**

`Строка, Неопределено` - значение настройки либо `Неопределено`, если ключ отсутствует.

## ПолучитьНастройку

```bsl
Конфигурация.ПолучитьНастройку(<Ключ>)
```

Возвращает независимое представление настройки без учёта регистра.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Ключ | `Строка` | Ключ настройки. |

**Возвращаемое значение:**

`Структура` с полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| НормализованныйКлюч | `Строка` | Ключ в нижнем регистре. |
| Значение | `Строка` | Сохранённое значение настройки. |
| База | `Строка` | Базовый каталог настройки. |

`Неопределено` возвращается, если ключ отсутствует. Изменение возвращённой структуры не влияет на конфигурацию.

## Ключи

```bsl
Конфигурация.Ключи()
```

**Возвращаемое значение:**

`Массив из Строка` - независимый массив последних написаний ключей в стабильном порядке без учёта регистра.

Изменение возвращённого массива не меняет конфигурацию.

## Установить

```bsl
Конфигурация.Установить(<Ключ>, <Значение>)
```

Добавляет или заменяет настройку без учёта регистра. При замене сохраняется новое написание ключа.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Ключ | `Строка` | Ключ настройки. |
| Значение | `Строка` | Значение настройки. |

Метод не проверяет представимость пары в CFG или `OSCRIPT_CONFIG`. Такая проверка выполняется при экспорте.
Метод ничего не возвращает.

## Предметные настройки

Для распространённых настроек доступны отдельные методы:

| Настройка | Метод установки | Метод получения |
| --- | --- | --- |
| `encoding.script` | `УстановитьКодировкуСценариев()` | `ПолучитьКодировкуСценариев()` |
| `systemLanguage` | `УстановитьСистемныйЯзык()` | `ПолучитьСистемныйЯзык()` |
| `lang.explicitImports` | `УстановитьРежимЯвныхИмпортов()` | `ПолучитьРежимЯвныхИмпортов()` |
| `runtime.default` | `УстановитьРежимИсполненияПоУмолчанию()` | `ПолучитьРежимИсполненияПоУмолчанию()` |
| `binaryData.inMemoryMaxSize` | `УстановитьМаксимальныйРазмерДвоичныхДанныхВПамяти()` | `ПолучитьМаксимальныйРазмерДвоичныхДанныхВПамяти()` |

Каждый метод установки принимает одно строковое значение, сохраняет его без преобразования и ничего не
возвращает. Метод получения возвращает сохранённую `Строка` либо `Неопределено`, если настройка отсутствует.
Библиотека не проверяет смысл значения: его интерпретирует движок при использовании конфигурации.

## Удалить

```bsl
Конфигурация.Удалить(<Ключ>)
```

Удаляет настройку без учёта регистра. Отсутствующий ключ допустим.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Ключ | `Строка` | Ключ удаляемой настройки. |

Метод ничего не возвращает.

## УстановитьСистемныйКаталогБиблиотек

```bsl
Конфигурация.УстановитьСистемныйКаталогБиблиотек(
    <Каталог>, <КаталогОтносительныхПутей> = Неопределено
)
```

Заменяет настройку `lib.system`.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| Каталог | `Строка` | Один путь без разделителя `;`. Крайние пробелы удаляются. |
| КаталогОтносительныхПутей | `Строка, Неопределено = Неопределено` | База пути. По умолчанию база конфигурации. |

Пустая строка является допустимым явным значением. Метод ничего не возвращает.

## ПолучитьСистемныйКаталогБиблиотек

```bsl
Каталог = Конфигурация.ПолучитьСистемныйКаталогБиблиотек()
```

Возвращает сохранённое значение `lib.system` без разрешения относительного пути либо `Неопределено`, если
настройка отсутствует.

## УстановитьДополнительныеКаталогиБиблиотек

```bsl
Конфигурация.УстановитьДополнительныеКаталогиБиблиотек(
    <Каталоги>, <КаталогОтносительныхПутей> = Неопределено
)
```

Заменяет список `lib.additional`.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| Каталоги | `Массив из Строка` | Пути без `;`. Пустые элементы пропускаются. |
| КаталогОтносительныхПутей | `Строка, Неопределено = Неопределено` | Общая база путей. По умолчанию база конфигурации. |

Порядок и повторы непустых путей сохраняются. Метод ничего не возвращает.

## ПолучитьДополнительныеКаталогиБиблиотек

```bsl
Каталоги = Конфигурация.ПолучитьДополнительныеКаталогиБиблиотек()
```

Возвращает независимый `Массив из Строка` без разрешения относительных путей либо `Неопределено`, если
`lib.additional` отсутствует. Явно пустому значению соответствует пустой массив.

## ДобавитьДополнительныйКаталогБиблиотек

```bsl
Конфигурация.ДобавитьДополнительныйКаталогБиблиотек(<Каталог>)
```

Добавляет один путь в конец `lib.additional`.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Каталог | `Строка` | Путь без `;`. Крайние пробелы удаляются, пустая строка пропускается. |

Новый список использует базу конфигурации. Существующий список сохраняет собственную базу. Метод ничего не
возвращает.

## ЗаписатьВФайл

```bsl
Конфигурация.ЗаписатьВФайл(
    <Путь>, <ПреобразованиеПутей> = Неопределено
)
```

Полностью заменяет CFG каноническим представлением.

**Параметры:**

| Имя | Тип и значение по умолчанию | Описание |
| --- | --- | --- |
| Путь | `Строка` | Путь к целевому CFG. Родительский каталог должен существовать. |
| ПреобразованиеПутей | `Строка, Неопределено = Неопределено` | Преобразование библиотечных путей; `Неопределено` выбирает `БезПреобразования`. |

Файл записывается в UTF-8 без BOM с окончаниями строк LF. Комментарии, дубли и исходное форматирование
не сохраняются. Перед заменой временный файл повторно разбирается.

Допустимость строкового значения режима не проверяется. Для неизвестного режима пути остаются как в источнике.
Используйте функции модуля [ПреобразованияПутейКонфигурацииЗапускаДвижка](ПреобразованияПутейКонфигурацииЗапускаДвижка.md).

Метод ничего не возвращает.

## ВСтрокуОкружения

```bsl
Конфигурация.ВСтрокуОкружения()
```

Формирует обратимое представление `OSCRIPT_CONFIG` без изменения окружения.

**Возвращаемое значение:**

`Строка` - упорядоченные пары с абсолютными библиотечными путями; для пустой конфигурации пустая строка.

Все значения заключаются в двойные кавычки, а двойные кавычки внутри значения удваиваются.

## УстановитьВПеременнуюОкружения

```bsl
Конфигурация.УстановитьВПеременнуюОкружения()
```

Формирует строку конфигурации и устанавливает `OSCRIPT_CONFIG` текущего процесса. Текущий каталог не меняется.
Метод ничего не возвращает.

Уже созданные загрузчики и разрешатели библиотек автоматически не перезагружаются.

## Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Публичный аргумент имеет неверный тип |
| `argument.required` | Обязательный путь или имя не заполнены |
| `argument.invalid_value` | Путь библиотеки недопустим |
| `engine_config.invalid_configuration` | Настройка непредставима в CFG или `OSCRIPT_CONFIG` |
| `engine_config.path_unresolved` | Библиотечный путь не удалось разрешить |
| `engine_config.write_failed` | CFG не удалось записать или безопасно заменить |
| `engine_config.environment_failed` | `OSCRIPT_CONFIG` не удалось установить |

Предметные ошибки могут содержать исходную причину. Проверяйте всю цепочку через библиотеку `errors`.

## Пример

```bsl
Конфигурация = Новый КонфигурацияЗапускаДвижка();
Конфигурация.УстановитьБазовыйКаталог("C:/Projects/example");
Конфигурация.Установить("lang.explicitImports", "warn");
Конфигурация.ДобавитьДополнительныйКаталогБиблиотек("./lib");

Если Конфигурация.Содержит("LANG.EXPLICITIMPORTS") Тогда
    Сообщить(Конфигурация.ПолучитьЗначение("lang.explicitImports"));
КонецЕсли;

Конфигурация.ЗаписатьВФайл(
    "C:/Projects/example/build/oscript.cfg",
    ПреобразованияПутейКонфигурацииЗапускаДвижка.ОтносительноФайла()
);
```
