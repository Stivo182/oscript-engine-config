# Изменение и экспорт конфигурации

`КонфигурацияЗапускаДвижка` хранит регистронезависимый набор строковых настроек и базовые каталоги,
необходимые для разрешения библиотечных путей.

## Произвольная конфигурация

```bsl
Конфигурация = Новый КонфигурацияЗапускаДвижка();
Конфигурация.УстановитьБазовыйКаталог("C:/Projects/example");

Конфигурация.УстановитьРежимЯвныхИмпортов("warn");
Конфигурация.УстановитьКодировкуСценариев("utf-8");
Конфигурация.УстановитьСистемныйЯзык("ru");
Конфигурация.УстановитьРежимИсполненияПоУмолчанию("native");
Конфигурация.УстановитьМаксимальныйРазмерДвоичныхДанныхВПамяти("50m");
Конфигурация.УстановитьСистемныйКаталогБиблиотек("./lib/system");

Каталоги = Новый Массив;
Каталоги.Добавить("./lib/project");
Каталоги.Добавить("./lib/shared");
Конфигурация.УстановитьДополнительныеКаталогиБиблиотек(Каталоги);
```

Если базовый каталог не задан, объект фиксирует текущий каталог при установке каждой настройки. Общие методы
`Установить()`, `ПолучитьЗначение()`, `ПолучитьНастройку()`, `Содержит()` и `Удалить()` работают с ключами без учёта регистра.

## Каталоги библиотек

`УстановитьСистемныйКаталогБиблиотек()` заменяет `lib.system`.
`УстановитьДополнительныеКаталогиБиблиотек()` заменяет весь список `lib.additional`, сохраняя порядок и повторы.
`ДобавитьДополнительныйКаталогБиблиотек()` добавляет один путь в конец существующего списка.

Путь не может содержать `;`, потому что этот символ является разделителем `lib.additional`. Пустые элементы
списка пропускаются.

## Запись CFG

```bsl
Конфигурация.ЗаписатьВФайл(
    "build/oscript.cfg",
    ПреобразованияПутейКонфигурацииЗапускаДвижка.ВАбсолютные()
);
```

Файл полностью заменяется каноническим представлением:

- одна пара `Ключ=Значение` на строку;
- стабильная сортировка ключей;
- UTF-8 без BOM;
- окончания строк LF;
- без комментариев, дублей и исходного форматирования.

Перед заменой временный файл повторно разбирается. Существующий CFG временно перемещается в файл отката.
Если после аварийного завершения файл отката остался, следующая запись прекращается и требует ручного
восстановления.

Режимы путей:

| Режим | Поведение |
| --- | --- |
| `БезПреобразования()` | Сохраняет строки значений без пересчёта |
| `ВАбсолютные()` | Разрешает `lib.system` и каждый элемент `lib.additional` по базе источника |
| `ОтносительноФайла()` | Пересчитывает библиотечные пути относительно каталога целевого CFG |

Если относительный путь построить нельзя, сохраняется абсолютный путь.

## Строка окружения

```bsl
СтрокаОкружения = Конфигурация.ВСтрокуОкружения();
```

Метод возвращает обратимое представление `OSCRIPT_CONFIG`, заключает значения в кавычки и переводит
библиотечные пути в абсолютные. Окружение процесса не изменяется.

```bsl
Конфигурация.УстановитьВПеременнуюОкружения();
```

Этот вызов изменяет `OSCRIPT_CONFIG` текущего процесса. Он не перезагружает уже созданные разрешатели библиотек
и не меняет текущий каталог.
