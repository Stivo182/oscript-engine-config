# ПреобразованияПутейКонфигурацииЗапускаДвижка

Публичный модуль со способами преобразования библиотечных путей при записи методом
`КонфигурацияЗапускаДвижка.ЗаписатьВФайл()`.

## БезПреобразования

```bsl
Преобразование = ПреобразованияПутейКонфигурацииЗапускаДвижка.БезПреобразования()
```

Возвращает строку `"БезПреобразования"`. Значения `lib.system` и `lib.additional` записываются без пересчёта.
Это преобразование используется по умолчанию.

## ВАбсолютные

```bsl
Преобразование = ПреобразованияПутейКонфигурацииЗапускаДвижка.ВАбсолютные()
```

Возвращает строку `"ВАбсолютные"`. Каждый библиотечный путь разрешается относительно базы победившего источника
и записывается абсолютным.

## ОтносительноФайла

```bsl
Преобразование = ПреобразованияПутейКонфигурацииЗапускаДвижка.ОтносительноФайла()
```

Возвращает строку `"ОтносительноФайла"`. Библиотечные пути сначала разрешаются в абсолютные, затем по возможности
пересчитываются относительно каталога целевого CFG. Если относительное представление невозможно, сохраняется
абсолютный путь.

## Пример

```bsl
Конфигурация.ЗаписатьВФайл(
    "C:/Projects/example/build/oscript.cfg",
    ПреобразованияПутейКонфигурацииЗапускаДвижка.ОтносительноФайла()
);
```

Передавайте результаты функций модуля, а не строковые литералы. `ЗаписатьВФайл()` проверяет тип преобразования,
но не проверяет его значение; неизвестная строка фактически оставляет пути без преобразования.
