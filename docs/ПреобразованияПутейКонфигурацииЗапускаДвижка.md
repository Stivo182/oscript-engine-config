
## БезПреобразования

**Синтаксис:**

```bsl
ПреобразованияПутейКонфигурацииЗапускаДвижка.БезПреобразования()
```

**Тип значения:**

Строка.

**Описание:**

Возвращает строку `"БезПреобразования"`. Значения `lib.system` и `lib.additional` записываются без пересчета.
Это преобразование используется по умолчанию.

## ВАбсолютные

**Синтаксис:**

```bsl
ПреобразованияПутейКонфигурацииЗапускаДвижка.ВАбсолютные()
```

**Тип значения:**

Строка.

**Описание:**

Возвращает строку `"ВАбсолютные"`. Каждый библиотечный путь разрешается относительно базы победившего источника
и записывается абсолютным.

## ОтносительноФайла

**Синтаксис:**

```bsl
ПреобразованияПутейКонфигурацииЗапускаДвижка.ОтносительноФайла()
```

**Тип значения:**

Строка.

**Описание:**

Возвращает строку `"ОтносительноФайла"`. Библиотечные пути сначала разрешаются в абсолютные, затем по возможности
пересчитываются относительно каталога целевого CFG. Если относительное представление невозможно, сохраняется
абсолютный путь.

## Пример

```bsl
Конфигурация.ЗаписатьВФайл(
    "C:/Projects/example/build/oscript.cfg",
    ПреобразованияПутейКонфигурацииЗапускаДвижка.ОтносительноФайла()
);
```

Передавайте результаты функций модуля, а не строковые литералы. `ЗаписатьВФайл()` отклоняет неизвестное
значение с кодом ошибки `argument.invalid_value`.
