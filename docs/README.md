# Документация API

Документация по публичному API пакета `engine-config`. Пакет рассчитывает конфигурацию запуска OneScript,
позволяет изменять ее в памяти, экспортировать в CFG и окружение, а также выполнять статический поиск библиотек.

## Руководства

- [Построение конфигурации](ПостроениеКонфигурации.md)
- [Изменение и экспорт конфигурации](ИзменениеИЭкспортКонфигурации.md)
- [Поиск библиотек](ПоискБиблиотек.md)

## Классы

- [КонфигурацияИнтерпретатора](КонфигурацияИнтерпретатора.md) - изменяемая конфигурация и операции экспорта
- [ЛокаторБиблиотекПоКонфигурации](ЛокаторБиблиотекПоКонфигурации.md) - каталоги поиска и статический поиск библиотек
- [ПостроительКонфигурацииИнтерпретатора](ПостроительКонфигурацииИнтерпретатора.md) - объединение CFG и окружения
