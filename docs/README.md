# Документация API

Документация по публичному API пакета `engine-config`. Пакет рассчитывает конфигурацию запуска OneScript,
позволяет изменять её в памяти, экспортировать в CFG и окружение, а также выполнять статический поиск библиотек.

## Руководства

- [Построение конфигурации](ПостроениеКонфигурации.md)
- [Изменение и экспорт конфигурации](ИзменениеИЭкспортКонфигурации.md)
- [Поиск библиотек](ПоискБиблиотек.md)

## Классы

- [КонфигурацияЗапускаДвижка](КонфигурацияЗапускаДвижка.md) - изменяемая конфигурация и операции экспорта
- [ЛокаторБиблиотекЗапускаДвижка](ЛокаторБиблиотекЗапускаДвижка.md) - каталоги поиска и статический поиск библиотек
- [ПостроительКонфигурацииЗапускаДвижка](ПостроительКонфигурацииЗапускаДвижка.md) - объединение CFG и окружения
