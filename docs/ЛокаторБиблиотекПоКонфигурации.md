# ЛокаторБиблиотекПоКонфигурации

Публичный объект для разрешения библиотечных путей и статического поиска каталогов библиотек. Локатор
создается по одной или нескольким конфигурациям запуска и хранит неизменяемый снимок настроек `lib.system`
и `lib.additional`.

## Создание

```bsl
Локатор = Новый ЛокаторБиблиотекПоКонфигурации(Конфигурация);

Конфигурации = Новый Массив;
Конфигурации.Добавить(ПерваяКонфигурация);
Конфигурации.Добавить(ВтораяКонфигурация);

ЛокаторНесколькихКонфигураций = Новый ЛокаторБиблиотекПоКонфигурации(Конфигурации);
```

| Имя | Тип | Описание |
| --- | --- | --- |
| Конфигурации | `КонфигурацияИнтерпретатора`, `Массив из КонфигурацияИнтерпретатора` | Конфигурации, библиотечные пути которых нужно разрешить. |

Относительные пути разрешаются при создании локатора. Последующие изменения конфигурации на него не влияют.

**Исключения:**

- `argument.invalid_type` - `Конфигурации` или элемент массива имеет неверный тип.
- `engine_config.path_unresolved` - библиотечный путь не удалось разрешить.
- `engine_config.invalid_configuration` - разрешенный путь `lib.additional` содержит разделитель списка.

## Методы

### ПолучитьСистемныеКаталоги

```bsl
Локатор.ПолучитьСистемныеКаталоги()
```

**Возвращаемое значение:**

`Массив из Строка` - независимый массив абсолютных системных каталогов в порядке
конфигураций. Конфигурации без заполненного `lib.system` пропускаются.

### ПолучитьДополнительныеКаталоги

```bsl
Локатор.ПолучитьДополнительныеКаталоги()
```

**Возвращаемое значение:**

`Массив из Строка` - независимый массив абсолютных путей `lib.additional`.

### ПолучитьКаталогиПоиска

```bsl
Локатор.ПолучитьКаталогиПоиска()
```

**Возвращаемое значение:** 

`Массив из Строка` - независимый массив абсолютных путей. Для каждой конфигурации
добавляются дополнительные каталоги в исходном порядке, затем системный каталог; после этого обрабатывается
следующая конфигурация. Повторы исключаются с сохранением первого вхождения, отсутствующие каталоги сохраняются.

### НайтиКаталогБиблиотеки

```bsl
Локатор.НайтиКаталогБиблиотеки(<Имя>)
```

Возвращает первый существующий каталог `<КаталогПоиска>/<Имя>`.

| Имя | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Непустое имя без крайних пробелов, `/`, `\`, `:`; не `.` и не `..`. |

**Возвращаемое значение:**

`Строка, Неопределено` - абсолютный путь к первому каталогу либо `Неопределено`.

Метод не проверяет содержимое каталога и не запускает загрузчики пакетов.

**Исключения:**

- `argument.invalid_type` - `Имя` имеет неверный тип.
- `argument.required` - `Имя` пусто или состоит из пробелов.
- `argument.invalid_value` - `Имя` содержит путь, крайние пробелы или равно `.` либо `..`.

### НайтиВсеКаталогиБиблиотеки

```bsl
Локатор.НайтиВсеКаталогиБиблиотеки(<Имя>)
```

Возвращает все существующие каталоги `<КаталогПоиска>/<Имя>`.

| Имя | Тип | Описание |
| --- | --- | --- |
| Имя | `Строка` | Непустое имя без крайних пробелов, `/`, `\`, `:`; не `.` и не `..`. |

**Возвращаемое значение:**

`Массив из Строка` - абсолютные пути в порядке поиска. Если библиотека не найдена,
возвращается пустой массив.

Метод использует те же правила проверки имени и коды ошибок, что и `НайтиКаталогБиблиотеки()`.
