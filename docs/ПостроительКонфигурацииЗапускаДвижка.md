# ПостроительКонфигурацииЗапускаДвижка

Публичный объект для построения конфигурации из явно упорядоченных CFG и строк `OSCRIPT_CONFIG`.
Пустой построитель не обращается к файлам, окружению или контексту процесса.

## Создание

```bsl
Построитель = Новый ПостроительКонфигурацииЗапускаДвижка();
Конфигурация = Построитель.Построить();
```

Создает пустой построитель. Полученная конфигурация не содержит настроек и каталогов поиска библиотек.
Конструктор не принимает параметров.

## Методы

### ДобавитьФайлКонфигурации

```bsl
Построитель.ДобавитьФайлКонфигурации(<Путь>)
```

Добавляет обязательный CFG-файл в конец списка источников.

| Имя | Тип | Описание |
| --- | --- | --- |
| Путь | `Строка` | Непустой путь к CFG-файлу. |

Относительный путь преобразуется в полный при вызове метода. Файл читается заново при каждом
`Построить()`. Отсутствующий, поврежденный или недоступный файл, а также каталог вместо файла являются ошибкой.

**Возвращаемое значение:** `ПостроительКонфигурацииЗапускаДвижка` - этот объект.

**Исключения:**

- `argument.invalid_type` - `Путь` имеет неверный тип.
- `argument.required` - `Путь` пуст или состоит из пробелов.

### ДобавитьНеобязательныйФайлКонфигурации

```bsl
Построитель.ДобавитьНеобязательныйФайлКонфигурации(<Путь>)
```

Добавляет необязательный CFG-файл в конец списка источников.

| Имя | Тип | Описание |
| --- | --- | --- |
| Путь | `Строка` | Непустой путь к CFG-файлу. |

Относительный путь преобразуется в полный при вызове метода. Файл читается заново при каждом
`Построить()` и пропускается, если отсутствует. Поврежденный или недоступный существующий файл,
а также каталог вместо файла являются ошибкой.

**Возвращаемое значение:** `ПостроительКонфигурацииЗапускаДвижка` - этот объект.

**Исключения:**

- `argument.invalid_type` - `Путь` имеет неверный тип.
- `argument.required` - `Путь` пуст или состоит из пробелов.

### ДобавитьНастройкиОкружения

```bsl
Построитель.ДобавитьНастройкиОкружения(<СтрокаНастроек>, [<РабочийКаталог>])
```

Добавляет явно переданную строку в грамматике `OSCRIPT_CONFIG`.

| Имя | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| СтрокаНастроек | `Строка` | - | Настройки, включая допустимую пустую строку. |
| РабочийКаталог | `Строка`, `Неопределено` | `Неопределено` | Необязательный существующий каталог - база относительных библиотечных путей. |

Строка сохраняется как значение источника. Переданный рабочий каталог фиксируется полным путем при вызове.
Если каталог не передан, текущий каталог используется при каждом `Построить()`.

**Возвращаемое значение:** `ПостроительКонфигурацииЗапускаДвижка` - этот объект.

**Исключения:**

- `argument.invalid_type` - `СтрокаНастроек` или `РабочийКаталог` имеет неверный тип.
- `argument.required` - `РабочийКаталог` пуст или состоит из пробелов.
- `argument.invalid_value` - `РабочийКаталог` не существует или не является каталогом.

### ДобавитьТекущееОкружение

```bsl
Построитель.ДобавитьТекущееОкружение([<РабочийКаталог>])
```

Добавляет текущее значение `OSCRIPT_CONFIG`, перечитываемое при каждом построении.

| Имя | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| РабочийКаталог | `Строка`, `Неопределено` | `Неопределено` | Необязательный существующий каталог - фиксированная база относительных путей. |

Если каталог не передан, текущий каталог используется при каждом `Построить()`. Отсутствующее или пустое
значение переменной не добавляет настроек.

**Возвращаемое значение:** `ПостроительКонфигурацииЗапускаДвижка` - этот объект.

**Исключения:**

- `argument.invalid_type` - `РабочийКаталог` имеет неверный тип.
- `argument.required` - `РабочийКаталог` пуст или состоит из пробелов.
- `argument.invalid_value` - `РабочийКаталог` не существует или не является каталогом.

### ДобавитьСтандартныеИсточники

```bsl
Построитель.ДобавитьСтандартныеИсточники()
```

Добавляет в позицию вызова три стандартных источника:

1. `<КаталогДвижка>/bin/oscript.cfg`;
2. `oscript.cfg` рядом со стартовым сценарием;
3. текущее `OSCRIPT_CONFIG`.

Пути CFG фиксируются при вызове. Автоматические CFG необязательны: отсутствующий файл пропускается, а
существующий поврежденный файл вызывает ошибку. Значение `OSCRIPT_CONFIG` и текущий рабочий каталог читаются
совместно при каждом `Построить()`.

**Возвращаемое значение:** `ПостроительКонфигурацииЗапускаДвижка` - этот объект.

### Построить

```bsl
Конфигурация = Построитель.Построить()
```

Читает источники в порядке добавления и возвращает новую независимую `КонфигурацияЗапускаДвижка`.
Метод не изменяет файлы, текущий каталог и окружение процесса.

**Исключения:**

- `engine_config.calculate_failed` - не удалось прочитать, разобрать или объединить источники.

## Порядок источников

Источники применяются в порядке добавления: каждый следующий источник перекрывает предыдущий для одноименных
настроек без учета регистра ключа. Последний источник задает значение, написание ключа и базу относительных
библиотечных путей. Источники не дедуплицируются.

```bsl
Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка()
    .ДобавитьФайлКонфигурации("config/base.cfg")
    .ДобавитьСтандартныеИсточники()
    .ДобавитьНастройкиОкружения("lib.additional=./lib", ТекущийКаталог())
    .Построить();
```

В этом примере явная строка окружения добавлена последней и перекрывает одноименные настройки предыдущих
источников.
