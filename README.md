# engine-config

`engine-config` - библиотека для построения и изменения конфигурации запуска OneScript.

Она может объединять настройки из `oscript.cfg` и `OSCRIPT_CONFIG`, изменять их в памяти, экспортировать в CFG
или окружение и выполнять статический поиск каталогов библиотек.

## Требования

- OneScript 2.2.0 или новее.

## Установка

Установите пакет из OPM:

```shell
opm install engine-config
```

Для проекта с `packagedef` добавьте зависимость:

```bsl
Описание.ЗависитОт("engine-config");
```

Подключите библиотеку в сценарии:

```bsl
#Использовать engine-config
```

## Быстрый старт

Постройте конфигурацию текущего запуска:

```bsl
#Использовать engine-config

Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка()
    .ДобавитьИсточникиТекущегоЗапуска()
    .Построить();
```

Источники применяются в порядке возрастания приоритета:

1. `<КаталогДвижка>/bin/oscript.cfg`;
2. `oscript.cfg` рядом с точкой входа;
3. `OSCRIPT_CONFIG`.

Отсутствующие CFG пропускаются. Построитель не меняет файлы, текущий каталог и окружение процесса. Пустой
построитель возвращает пустую конфигурацию. Произвольные источники можно добавить явно:

```bsl
Конфигурация = Новый ПостроительКонфигурацииЗапускаДвижка()
    .ДобавитьФайлКонфигурации("config/base.cfg")
    .ДобавитьНастройкиОкружения("lib.additional=./lib", ТекущийКаталог())
    .Построить();
```

Подробнее: [Построение конфигурации](docs/ПостроениеКонфигурации.md).

## Изменение и экспорт конфигурации

```bsl
Конфигурация = Новый КонфигурацияЗапускаДвижка();

Конфигурация.УстановитьРежимЯвныхИмпортов("warn");
Конфигурация.УстановитьСистемныйКаталогБиблиотек("./lib/system");
Конфигурация.ДобавитьДополнительныйКаталогБиблиотек("./lib/project");

РежимИмпортов = Конфигурация.ПолучитьРежимЯвныхИмпортов();
```

Ключи регистронезависимы. Повторная установка заменяет значение и сохраняет последнее написание ключа.

Запись полностью заменяет целевой файл каноническим CFG: UTF-8 без BOM, окончания строк LF, пары
`Ключ=Значение` в стабильном порядке. Каталог назначения должен существовать.

```bsl
Конфигурация.ЗаписатьВФайл(
    "build/oscript.cfg",
    ПреобразованияПутейКонфигурацииЗапускаДвижка.ОтносительноФайла()
);
```

`ВСтрокуОкружения()` возвращает `OSCRIPT_CONFIG` с абсолютными библиотечными путями и не меняет процесс.
`УстановитьВПеременнуюОкружения()` формирует ту же строку и изменяет окружение текущего процесса:

```bsl
СтрокаОкружения = Конфигурация.ВСтрокуОкружения();
Конфигурация.УстановитьВПеременнуюОкружения();
```

Подробнее: [Изменение и экспорт конфигурации](docs/ИзменениеИЭкспортКонфигурации.md).

## Поиск библиотек

```bsl
Локатор = Новый ЛокаторБиблиотекЗапускаДвижка(Конфигурация);

Каталоги = Локатор.ПолучитьКаталогиПоиска();
КаталогБиблиотеки = Локатор.НайтиБиблиотеку("my-library");
```

Сначала проверяются дополнительные каталоги в исходном порядке, затем системный. Локатор фиксирует снимок
библиотечных настроек при создании. Поиск не запускает `package-loader.os` и не проверяет наличие исполняемого
кода библиотеки.

Подробнее: [Поиск библиотек](docs/ПоискБиблиотек.md).

## Разработка

```shell
# Установка зависимостей проекта
opm install -l --dev

# Запуск всех тестов
oneunit e

# Сборка OPM-пакета
opm build .
```
